<h2>📝 Troubleshooting Guide</h2>

<h3>Problem: The app opens but shows no networks.</h3>
Solution: Make sure your computer has actually connected to WiFi networks before. If you are using a desktop PC with an Ethernet cable only, there may be no saved WiFi profiles. Try connecting to a WiFi network once, then run the app again.

<h3>Problem: Some passwords appear as blank.</h3>
Solution: This happens if the network uses a special authentication method (like enterprise security with a username and password). The app can only display passwords for personal home networks, not organizational ones.

<h3>Problem: I get an error saying "File not found."</h3>
Solution: Restart your computer and run the app again. If the issue persists, download the file once more, as the original download might have been corrupted.

<h3>Problem: The app does not start at all.</h3>
